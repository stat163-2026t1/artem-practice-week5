# Data

Two files, each as its publisher serves it. Downloaded 29 September 2026. No values were
altered.

- `world_bank_population.csv` — World Bank, *Population, total* (indicator `SP.POP.TOTL`),
  World Development Indicators, <https://data.worldbank.org/indicator/SP.POP.TOTL>. The CSV
  from the download archive, renamed from `API_SP.POP.TOTL_DS2_en_csv_v2_430592.csv`.
  Licence: CC BY 4.0.
- `une_rt_a.tsv` — Eurostat, *Unemployment by sex and age — annual data* (`une_rt_a`),
  <https://ec.europa.eu/eurostat/databrowser/view/une_rt_a/default/table>, in the TSV format
  of the Eurostat dissemination API. Licence: CC BY 4.0, source Eurostat.
